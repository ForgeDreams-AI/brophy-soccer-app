# Brand assets
Copy the team's brand assets here:
- `logo.png` — team logo (used for login screen, header, push icon, favicon)
- `login-bg.jpg` — login screen background photo
For the default Phoenix deployment, copy from the source repo's `teamhub/public/brand/`.
These are resolved via the team theme config (`theme.teams.js` → `assets`), so a
white-label team swaps files here (or points at its own paths) with no code changes.
